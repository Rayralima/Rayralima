### 🚦 SINTRA – Sistema de Predição de Risco de Acidentes

![Status](https://img.shields.io/badge/Status-Concluido-success)
![Python](https://img.shields.io/badge/Python-3.x-blue)
![Docker](https://img.shields.io/badge/Container-Docker-2496ED)

### 📋 Sobre o Projeto
O **SINTRA** é uma solução *end-to-end* de Engenharia de Dados e Machine Learning desenvolvida para analisar e prever riscos de acidentes de trânsito. O objetivo é fornecer insights visuais e preditivos para auxiliar na gestão de tráfego e segurança viária.

### 🚀 Arquitetura e Pipeline
O projeto foi construído seguindo as melhores práticas de Engenharia de Dados:
1.  **Coleta e Ingestão:** Tratamento de dados brutos de trânsito.
2.  **Processamento:** Limpeza e feature engineering com **Pandas**.
3.  **Modelagem:** Treinamento de algoritmo preditivo com **Scikit-learn**.
4.  **Visualização:** Dashboard interativo com **Dash/Plotly**.
5.  **Deploy:** Containerização com **Docker** e deploy em nuvem.

### 🛠️ Tecnologias Utilizadas
* **Linguagem:** Python
* **Machine Learning:** Scikit-learn
* **Manipulação de Dados:** Pandas, NumPy
* **Visualização & Web:** Plotly, Dash, Flask
* **Infraestrutura:** Docker

### 🤖 ChatBot Quiz Interativo com Visão Computacional e NLP

![Python](https://img.shields.io/badge/Python-3.x-blue)
![AI](https://img.shields.io/badge/AI-Deep_Learning-purple)
![Tech](https://img.shields.io/badge/Tech-YOLOv8_%7C_Transformers-green)

### 📄 Descrição
Solução avançada que integra **Automação**, **Visão Computacional** e **Processamento de Linguagem Natural (NLP)**.

Originalmente estruturado como um sistema de Quiz interativo, o projeto evoluiu para uma ferramenta capaz de interpretar dados visuais e textuais complexos. Ele utiliza **Deep Learning** para detectar objetos em imagens (YOLO) e extrair textos (OCR), combinando isso com modelos de linguagem (SBERT) para entender o contexto semântico das perguntas e respostas.

### ⚙️ Funcionalidades e Fluxo
1.  **Interação Inteligente:** Aplicação de questionários com validação de respostas baseada em lógica e similaridade semântica (NLP).
2.  **Análise Visual:** O sistema é capaz de receber imagens, identificar objetos e ler textos contidos nelas para gerar perguntas ou validar contextos.
3.  **Engine de IA:** Processamento de dados não estruturados utilizando pipelines modernos de Deep Learning.

### 💻 Stack Tecnológico

### 🧠 Inteligência Artificial & NLP
* **Sentence Transformer (SBERT):** Para criação de embeddings e análise de similaridade semântica entre perguntas e respostas.
* **Hugging Face Transformers:** Implementation de pipelines de modelos pré-treinados.
* **Frameworks:** PyTorch / TensorFlow.

### 👁️ Visão Computacional
* **Detecção de Objetos:** **YOLOv8 (Ultralytics)** treinado para identificação de padrões in imagens.
* **OCR:** Pré-processamento com **OpenCV** (filtros, binarização) e extração de texto com **Tesseract**.

### ⚙️ Core & Automação
* **Linguagem:** Python.
* **Lógica:** Estruturas de controle de fluxo e tratamento de dados dinâmico.

### 🏭 PharmaSet: Sistema Avançado de Otimização de Setup e Produtividade Industrial - (FACEPE)

![Status](https://img.shields.io/badge/Status-Concluido-green)
![Team](https://img.shields.io/badge/Team-Multidisciplinar_(Back_Dados)-blueviolet)
![Doc](https://img.shields.io/badge/Documentação-Formal_(IEEE/ABNT)-gray)

### 📋 Visão Geral do Projeto
Desenvolvimento de uma plataforma web robusta para modernizar os processos do **Laboratório Farmacêutico do Estado de Pernambuco (LAFEPE)**. O sistema foi projetado para garantir conformidade regulatória e eficiência operacional em três pilares críticos: **Qualidade, Produção e Treinamento Corporativo**.

O projeto seguiu rigorosos padrões de documentação de software (Planos de Projeto, Casos de Uso e Especificações Técnicas).

### 🧩 Arquitetura da Solução
O sistema opera em uma arquitetura de serviços desacoplada, garantindo escalabilidade e segurança:

* **Frontend & UX/UI:** Interfaces intuitivas focadas na experiência do usuário industrial (Desenvolvido pela equipe de Front/Design).
* **Backend (Minha Atuação):** APIs RESTful que centralizam a lógica de negócios e segurança de dados.
* **Banco de Dados:** Modelagem relacional para integridade dos registros fabris.

### 🚀 Módulos do Sistema
1.  **Módulo de Qualidade:** Rastreamento de não-conformidades e auditoria de lotes.
2.  **Módulo de Produção:** Controle de fluxo da linha de montagem e insumos.
3.  **Módulo de Auto-Treinamento:** Plataforma de capacitação para normas da ANVISA/Internas.

### 👨‍💻 Minha Contribuição (Backend & Dados)
Fui responsável pela implementação do **Core de Regras de Negócio** nas APIs, trabalhando em estreita colaboração com a **Equipe de Dados**:
* **Implementação de APIs:** Construção de endpoints seguros para consumo das interfaces web.
* **Regras de Negócio:** Tradução dos requisitos documentais em código Python/NestJS, implementando validações estritas de entrada de dados.
* **Tratamento de Exceções:** Criação de camadas de segurança e tratamento de erros para garantir a robustez das transações no banco.
* **Dashboards:** Colaboração na elaboração de painéis de monitoramento, garantindo que os dados servidos pelas APIs estivessem estruturados corretamente para visualização.
* **Integridade de Dados:** Validação de *schemas* e tratamento de exceções para garantir a confiabilidade dos relatórios finais.

### 🛠️ Tecnologias
* **Backend:** TypeScript / NestJS
* **Banco de Dados:** SQL (PostgreSQL)
* **Arquitetura:** MVC / Clean Architecture
* **Qualidade:** Validação de Dados e Tratamento de Erros
